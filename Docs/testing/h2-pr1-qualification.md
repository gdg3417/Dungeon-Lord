## Measurement contract

Use fresh rendered player processes and exact seed copies for each cell. Record launch-through-exit and Bootstrap-to-ready time. After 120 warm-up frames, collect at least 120 samples spanning at least 15 seconds of advancing focused production time. A fixed buffer fails on overflow. Capture real wall-clock frame intervals, per-frame main/render/GC counters when supported, work from ordinal/sequence/tick/history and attempted write and observed publication counters. A frame may contain several effects. The classification gives settlement, admission and tick precedence so distributions do not double-count. Raw counters and all overlaps remain in the frame records. This reference gives frame and write distributions, not a paired H2 result or a per-action release score.

Use the separate memory lane for allocation calibration and explicit overlap checkpoints at canonical persistence preparation/readback. The writer holds the original, candidate, active-before and readback payloads. Sum each distinct byte array once and retain the managed heap and Unity allocator samples at those points. Root a managed allocation and an independently freed native allocation during calibration. Unavailable process/runtime counters or incomplete samples cannot establish a limit. The managed heap and process private/working-set observations include other runtime allocations. The checked payload is a lower bound on the writer's live bytes. Candidate-only execution graph and UI preview attribution, uncertainty-pair release and candidate reclamation remain prerequisites for H2 scoring when those objects exist.

## Bootstrap and review limitation

Normal-player structural construction and legacy append controls retire behind the established diagnostics policy. Legacy starter setup remains available for zero-floor virgin canonical saves and empty active Floor 1. Actual StructuralEditService first-room support requires an existing **inactive** empty floor; active-floor construction requires an established room tail. Production can replace subsequent append construction, but cannot yet replace fresh-game starter setup. This limitation requires external review and owner acceptance; fresh-game graphical parity is not claimed. No broader first-room/floor-lifecycle change is included.

Replacement, deletion, lifecycle, optional branches, acquisition/custody, Research and Run/Observe stay available in Bootstrap. Focus Room is deferred because it needs coordinated Normal selection/input ownership. Existing A5 selection/movement and Focus Floor are preserved.

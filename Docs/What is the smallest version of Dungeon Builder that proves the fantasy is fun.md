What is the smallest version of Dungeon Builder that proves the fantasy is fun?

**MVP gameplay scope**

> **Owner scope amendment (2026-10-18):** No sub-dungeons, including the Mana Farm, are in the five-floor MVP or initial public release. See the [dated scope decision](planning/decisions/mvp-mana-farm-post-launch-scope-amendment.md). Earlier sub-dungeon MVP or release statements are superseded.

Include

- Dungeon core

- 1 main dungeon with up to 5 floors

- 2 monster families only (Undead and Goblinoid)

- Mana generation

- Basic heat system with only Peace, Notice, Concern

- Adventurers with 5 classes only

- Loot tiers up to Steel

- Research system with 1 slot

- Idle offline mana calculation


Explicitly exclude for MVP

- Prestige

- Seasonal events

- PvP or leaderboards

- Hero adventurers

- All sub-dungeons, including Mana Farm, through initial public release

- Advanced diplomacy

- More than 3 heat states

- Boss sets beyond one per family

## 1. Baseline and critical-path change

PR #245 has **implemented** an autonomous, timed, single-Floor-1, single-party foreground C2 game loop with durable exactly-once terminal settlement under its qualified profile, preserving active canonical edits and qualified C2 monster-condition reconciliation. It included usability and measured performance corrections; exact scope in `Docs/testing/evidence/living-dungeon-b3b2/qualification.md`. This makes a player-facing base for Phase 8 but **does not** supply automatic active Floor 2–5 descent/waiting, concurrently occupied distinct floors, or full **offline adventurer** event processing. The current B3B2 event-boundary stalls remain measurable performance debt, not an excuse to approximate outcomes.

The research prototype's local MVP claim affordance is not the two-slot, cost-charged, offline-progressing target. Floor 2 `ac_100` remains a deployed permission. Existing loot uses an abstract room roll, not paid stocked-item identity. Therefore new research/economy/save authority must precede dependent Phase 8 game content.

**Public release gate**: D196 accepts local offline-first research for the single-player MVP; it requires genuine remote start+claim verification **before the public production release**, not as a feature that must wait until after release. All sub-dungeons remain excluded from the MVP *and initial release*.
